# Plan: Independent connection deletion + no auto-connection for PDF annotations

## Feature 1 — Select a connection, right-click, delete it

Today edges are purely visual: `svg.edges` has `pointer-events: none` and there is no edge selection state. Deletion only happens as a cascade when a card is deleted.

**State** — `src/lib/selection.svelte.ts`
- Add `edge: ''` (selected edge id) and `edgeMenu: null as { id: string; x: number; y: number } | null` to the selection store.
- Add `selectEdge(id)` that sets `edge` and clears card/group selection and menus; make `selectOnly`, `selectGroup`, and `clearSelection` also reset `edge`/`edgeMenu`.

**Hit targets & rendering** — `src/components/EdgesLayer.svelte` + `src/style.css`
- Render an invisible, wider hit path (stroke-width ~14, transparent, `pointer-events: stroke`) alongside each visible connection path. The svg stays `pointer-events: none`; only hit paths accept events.
- Pointerdown on a hit path → `stopPropagation()` (so it doesn't trigger pan/marquee/dblclick-add-card) → `selectEdge(edge.id)`.
- Context menu on a hit path → `stopPropagation()` + call a new `onedgecontextmenu(edge.id, event)` prop.
- Visible path gets a `selected` style (highlight stroke/color) when `selection.edge === edge.id`.
- Hit paths are disabled while connecting (`.board.connecting`) and in hand/pan mode, so they never interfere with `document.elementFromPoint` snap hit-testing in `updateConnectionPreview` or panning.

**Menu & delete** — `src/components/Board.svelte` + `src/App.svelte`
- Board wires `onedgecontextmenu`: computes board-relative coordinates and sets `selection.edgeMenu`, following the existing group-menu pattern (`.floating-menu` with `.danger` button).
- New floating menu renders a "Delete connection" item; App gets a `removeEdge(id)` callback that commits `{ collection: 'edges', id, before: snapshot, after: undefined }` (full undo support for free), clears edge selection, and notifies "Connection deleted. Undo to restore."
- `handleKey` in Board: `Delete` with an edge selected deletes the edge (matching card behavior); Escape already clears via `clearSelection`. Marquee finish and background clicks clear the edge selection too.

## Feature 2 — No automatic connection from PDF annotations

In `src/App.svelte`:
- `placeHighlight()` (~line 526): remove the `makeEdge(...)` creation and edge commit — only the placement is committed.
- `drop()` (~line 535): remove the anchor auto-edge block.
- Remove the now-unused `makeEdge` helper in App.svelte (and any imports it orphans). Board.svelte's own `makeEdge` stays — manual connections are unaffected.
- The entity's `anchor` field stays, so the "p. N · Source" chip still lets you jump back to the quote (per your choice), but no edge is drawn between the PDF card and the annotation card.
